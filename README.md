# Tuck Shop Till

A back to basics app. You will build a till for the college tuck shop: item buttons, a running total, a basket, taking payment and a meal deal.

Follow the **Back to Basics: Tuck Shop Till** task sheet. Each stage has three parts: **Learn it**, **Build it** and **Try it yourself**.

## Get started

1. In Android Studio, choose **File > New > Project from Version Control** (or **Clone Repository** on the welcome screen).
2. Paste the URL of **this** repository and choose the folder you have been told to use.
3. Wait for Gradle to finish syncing. The first sync can take a few minutes. If Android Studio offers to upgrade the Android Gradle Plugin, click **Dismiss**.
4. Pick your virtual phone and press **Run**. You should see "Your till goes here".
5. Open `app/src/main/java/com/example/tuckshoptill/MainActivity.kt`. All of your code goes below the line that says **YOUR CODE STARTS HERE**.

## Save your work to GitHub after every stage

1. Open the **Commit** panel (the tick icon on the left, or **Ctrl+K**).
2. Tick the files you changed and write a short message that says what you did, for example `Stage 2: total goes up`.
3. Press **Commit and Push**, then **Push**.

## If you get stuck

- Red code: hover over it and read the message. Missing import? Press **Alt+Enter**.
- App crashes: open **Logcat**, find the first red line that mentions `MainActivity.kt`, and click it.
- Still stuck: check the task sheet, ask the person next to you, then put your hand up.
